21.1 关键公式 — 领域1-4 / Key Formulas — Domains 1-4

📖 来源 / Sources: 综合 / Consolidated: Brauer Ch.36 (System Safety) · Yates Ch.3 (Math Review) · Yates Ch.13 (Statistics) · Yates Ch.14 (Electrical)
公式 / Formula 领域 / Domain 用途 / Use
坠落间隙 = 系索长度 + 减速距离 + 工人身高 + 安全系数 (通常合计3英尺: 1.5英尺减速 + 1.5英尺安全)
Fall Clearance = Lanyard Length + Deceleration Distance + Worker Height + Safety Factor (typically 3 ft total: 1.5 ft decel + 1.5 ft safety)		 D1 Calculate required clearance below working surface. Standard lanyard = 6 ft + 3.5 ft decel + 6 ft worker + 1 ft safety = ~17.5 ft计算工作表面下方所需间隙。标准系索 = 6英尺 + 3.5英尺减速 + 6英尺工人身高 + 1英尺安全 = 约17.5英尺
噪声剂量 (%) = 100 x (C1/T1 + C2/T2 + ... + Cn/Tn)
Noise Dose (%) = 100 x (C1/T1 + C2/T2 + ... + Cn/Tn)		 D2 Determine compliance with 29 CFR 1910.95. C = actual exposure time at noise level; T = reference duration at that level. Dose > 100% = overexposure.确定是否符合29 CFR 1910.95。C = 该噪声水平的实际暴露时间；T = 该水平的参考持续时间。剂量 > 100% = 过度暴露。
TWA (噪声) = 16.61 x log10(D/100) + 90
TWA (noise) = 16.61 x log10(D/100) + 90		 D2 Convert noise dose percentage to 8-hour TWA in dBA (5 dB exchange rate). D = dose in percent.将噪声剂量百分比转换为8小时TWA dBA值（5 dB交换率）。D = 剂量百分比。
TRIR = (可记录伤害总数 x 200,000) / 总工时
TRIR = (Total Recordable Injuries x 200,000) / Total Hours Worked		 D2 OSHA recordable injury rate per 100 full-time workers. 200,000 = 100 workers x 2,000 hrs/yr.每100名全职工人的OSHA可记录伤害率。200,000 = 100名工人 x 2000小时/年。
DART = (缺勤、受限或转岗案例 x 200,000) / 总工时
DART = (Cases with Days Away, Restricted, or Transfer x 200,000) / Total Hours Worked		 D2 Severity-based rate; subset of TRIR. Measures more serious injuries.基于严重程度的比率；TRIR的子集。衡量更严重的伤害。
LTIFR = (损失工时伤害数 x 1,000,000) / 总工时
LTIFR = (Lost Time Injuries x 1,000,000) / Total Hours Worked		 D2 Lost time injury frequency rate (international/ANSI Z16). Uses 1,000,000 not 200,000.损失工时伤害频率（国际/ANSI Z16）。使用1,000,000而非200,000。
RPN = 严重度 x 发生度 x 检测度
RPN = Severity x Occurrence x Detection		 D3 Risk Priority Number in FMEA. Each rated 1-10; higher RPN = higher priority for corrective action.FMEA中的风险优先数。各项评分1-10；RPN越高 = 纠正措施优先级越高。
风险 = 可能性 x 严重度
Risk = Likelihood x Severity		 D3 Fundamental risk equation. Used in risk matrices and qualitative assessment.基本风险方程。用于风险矩阵和定性评估。
严重度率 = (损失工作日数 x 200,000) / 总工时
Severity Rate = (Days Lost x 200,000) / Total Hours Worked		 D2 Measures the severity of lost-time injuries by counting days lost.通过计算损失工作日数来衡量损失工时伤害的严重程度。
坠落间隙快速计算 / Fall Clearance Quick Calc: 6英尺系索 + 3.5英尺减速 + 6英尺工人身高 + 1英尺安全 = 约16.5-17.5英尺最低要求。对于SRL，请参考制造商规格——通常所需间隙更少。
6' lanyard + 3.5' deceleration + 6' worker height + 1' safety = ~16.5-17.5 ft minimum. For SRLs, refer to manufacturer specs — generally less clearance needed.
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: A facility with 350 employees working 2,000 hours each reports 7 recordable injuries. What is the TRIR? TRIR计算？
答题要点 / Key point: Hours = 700,000. TRIR = (7 × 200,000)/700,000 = 2.0. Remember: TRIR/DART use 200,000; LTIFR uses 1,000,000. Fall clearance = lanyard + decel + worker + safety (~17.5 ft for 6-ft lanyard). 记住200,000与1,000,000的区别。

FMEA
失效模式与影响分析 / Failure Mode & Effects Analysis		 归纳法（自下而上） / Inductive (bottom-up) 组件 -> 系统 / Component -> System Detailed analysis of equipment/process components; identifying single-point failures设备/过程组件的详细分析；识别单点故障 RPN (SxOxD); 优先行动清单 / RPN (SxOxD); prioritized action list

21.5 风险矩阵与ALARP / Risk Matrix & ALARP

📖 来源 / Sources: Brauer Ch.34 (Risk, Risk Assessment) · Yates Ch.24 (Risk Assessment and Management)
风险等级 / Risk Level 所需行动 / Action Required ALARP概念 / ALARP Concept
高（红色） / High (Red) Unacceptable — immediate action required; work should not proceed. Risk reduction is mandatory.不可接受——需立即行动；工作不得继续。降低风险是强制性的。 ALARP = 尽可能降低至合理可行 / As Low As Reasonably Practicable.

The region between unacceptable and broadly acceptable where risk must be reduced to the lowest level that is reasonably practicable. "Reasonably practicable" means the cost of further reduction is not grossly disproportionate to the benefit gained.
在不可接受和广泛可接受之间的区域，风险必须降至合理可行的最低水平。"合理可行"意味着进一步降低的成本不会与所获收益严重不成比例。

关键原则 / Key principle: Risk reduction is not required at all costs — there is a point of diminishing returns where further reduction becomes disproportionately expensive relative to the safety benefit.并非不惜一切代价降低风险——存在一个收益递减点，进一步降低相对于安全收益而言变得不成比例地昂贵。
中（黄色） / Medium (Yellow) Tolerable if ALARP — risk reduction measures should be implemented where reasonably practicable; ongoing monitoring required.如达到ALARP则可容忍——应在合理可行的情况下实施降低风险措施；需要持续监测。
低（绿色） / Low (Green) Broadly acceptable — no further action required beyond maintaining existing controls and monitoring for change.广泛可接受——除维护现有控制措施和监测变化外，无需进一步行动。
风险 = 可能性（概率）x 严重度（后果） / Risk = Likelihood (Probability) x Severity (Consequence)
Typically scored on 4x4, 5x5, or 5x6 matrix. Always define your scale before using.通常按4x4、5x5或5x6矩阵评分。使用前务必定义评分标准。
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: A hazard is rated Likelihood = 4, Severity = 5 on a 5x5 matrix (High = 13-25). What is the classification? 风险矩阵评级？
答题要点 / Key point: R = L × S = 4 × 5 = 20 → High risk, immediate action. ALARP = reduce risk until cost is grossly disproportionate to benefit — not at all costs. 记住R=L×S与ALARP概念。

Water (Class A extinguishers) must NEVER be used on Class B, C, or D fires. Class C fires require non-conductive agents. Class K (commercial kitchens) requires wet chemical systems. 水（A类灭火器）绝不能用于B、C或D类火灾。C类火灾需要不导电的介质。K类（商业厨房）需要湿式化学系统。
🧠 记忆口诀 / Mnemonic: 75-50-75-30：灭火器行走距离——A=75 ft、B=50 ft、D=75 ft、K=30 ft。 / Extinguisher travel distances.
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: A fire in a commercial kitchen deep fryer requires which class of extinguisher? 商用厨房油炸锅火灾用哪类灭火器？
答题要点 / Key point: Class K — wet chemical (potassium-based, saponification). Class C = energized electrical (CO2/dry chemical, never water); Class D = combustible metals (dry powder). 记住A/B/C/D/K对应灭火剂与危险介质。
