13.1 NFPA 101——生命安全规范 · NFPA 101 — Life Safety Code☆

📖 来源 / Sources: NFPA 101 (Life Safety Code) · Brauer Ch.16 (Fire Protection and Prevention) · Yates Ch.10 (Fire Protection and Prevention)

NFPA 101 is the most widely adopted fire safety code in the United States. It establishes minimum requirements for the design, operation, and maintenance of buildings to protect occupants from fire, smoke, and panic. NFPA 101是美国采纳最广泛的消防安全规范。它规定了建筑设计、运营和维护的最低要求，以保护建筑内人员免受火灾、烟雾和恐慌的伤害。

Occupancy Classification / 建筑用途分类

NFPA 101 classifies buildings by the type of occupancy and the activities conducted within them. The classification drives all egress requirements: NFPA 101根据建筑用途类型和其中进行的活动进行分类。分类决定所有疏散要求：

Occupancy / 用途Examples / 示例
Assembly (Ch 12-13) / 人员聚集50+ persons: theaters, churches, restaurants, arenas / 50人以上：剧院、教堂、餐厅、体育馆
Educational (Ch 14-15) / 教育Schools, daycare / 学校、日托机构
Health Care (Ch 18-19) / 医疗保健Hospitals, nursing homes — occupants incapable of self-preservation / 医院、养老院——居住者无法自行逃生
Detention & Correctional (Ch 22-23) / 拘留与惩教Prisons, jails / 监狱、看守所
Residential (Ch 24-31) / 居住Hotels, apartments, dormitories / 酒店、公寓、宿舍
Mercantile (Ch 36-37) / 商业Stores, markets / 商店、市场
Business (Ch 38-39) / 办公Offices, professional services / 办公室、专业服务
Industrial (Ch 40-41) / 工业Factories, manufacturing / 工厂、制造
Storage (Ch 42-43) / 仓储Warehouses, parking garages / 仓库、停车库

疏散通道 · Means of Egress☆

The continuous and unobstructed path of travel from any point in a building to a public way. Three components: 从建筑内任意一点到公共道路的连续畅通的通行路径。三个组成部分：

  1. Exit Access / 出口通道: The path leading TO an exit (e.g., corridor to stairwell door).通向出口的路径（如：通往楼梯间的走廊）。
  2. Exit / 出口: The protected portion providing a protected path to the exit discharge (e.g., enclosed stairwell, smoke-proof tower, horizontal exit).提供通往出口疏散点的保护通道部分（如：封闭楼梯间、防烟楼梯、水平出口）。
  3. Exit Discharge / 出口疏散点: The path FROM the exit to a public way (e.g., exterior door to sidewalk).从出口到公共道路的路径（如：从外部门到人行道）。
⚠ CSP 考试技巧 / Exam Tip:
Health Care occupancy is defined by the occupants' INABILITY to self-preserve, not just by medical services. This drives stricter requirements (protected corridors, horizontal exits, smoke compartments). Remember the three-part egress chain: exit access → exit → exit discharge. 医疗保健场所由居住者无法自行逃生来定义，而非仅凭医疗服务。这驱动更严格的要求（保护走廊、水平出口、防烟分区）。记住三段疏散链：出口通道 → 出口 → 出口疏散点。
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: A facility with occupants unable to self-preserve is classified as which occupancy? 居住者无法自行逃生的场所属于哪类用途？
答题要点 / Key point: Health Care occupancy is defined by occupants' INABILITY to self-preserve, not by medical services — this drives stricter egress requirements. 医疗保健场所以"居住者无法自行逃生"定义，而非医疗服务。
🧠 记忆口诀 / Mnemonic: AED = Access → Exit → Discharge（出口通道 → 出口 → 出口疏散点）——疏散链三段顺序，常考顺序题。 / The three-part egress chain in order.

13.2 Egress Design — Key NFPA 101 Requirements疏散设计——NFPA 101关键要求

📖 来源 / Sources: NFPA 101 (Life Safety Code) · Brauer Ch.16 (Fire Protection and Prevention)
Parameter / 参数Requirement / 要求Notes / 备注
Minimum Exit Doors / 最少出口门数 At least 2 exits from most occupancies大多数场所至少2个出口 Required when occupant load or travel distance exceeds thresholds当人员负荷或行走距离超过阈值时需要
Exit Width / 出口宽度 0.2 in/person (level surfaces)
0.3 in/person (stairs)		 Capacity factor. Minimum door width typically 32 in clear opening.
Travel Distance / 行走距离 Varies by occupancy (typically 150-400 ft) From most remote point to nearest exit. Shorter for higher-hazard occupancies.从最远点到最近出口。高风险场所要求更短。
Common Path of Travel / 共同通行路径 Varies by occupancy (20-100 ft typical) Distance before a person has a choice of two exits. Always shorter than total travel distance.在可选择两个出口之前的距离。始终短于总行走距离。
Dead-End Corridor / 死端走廊 Max 20-50 ft depending on occupancy and sprinkler protection A corridor that continues past an exit; occupants must retrace their steps.继续延伸超过出口的走廊；居住者必须折返。
Panic Hardware / 紧急推杆锁 Required on doors serving Assembly occupancies with occupant load of 100+ Must unlatch with 15 lb maximum force.必须用最大15磅的力就能打开。
Door Swing / 门开启方向 Must swing in direction of egress travel when serving 50+ occupants or high-hazard contents Prevents crush at exit doors during emergency evacuation.防止紧急疏散时在出口门处发生踩踏。

Exit Width Calculation Example / 出口宽度计算示例

A business occupancy must evacuate 400 occupants via level corridors. Required total corridor width = 400 persons × 0.2 in/person = 80 inches. If evacuated via stairs instead: 400 × 0.3 = 120 inches of stair width. 某办公场所需通过水平走廊疏散400人。所需走廊总宽度 = 400人 × 0.2英寸/人 = 80英寸。若改经楼梯疏散：400 × 0.3 = 120英寸楼梯宽度。

Required Egress Width (所需疏散宽度) = Occupant Load (人员负荷) × Capacity Factor (容量因子)
Capacity Factor: 0.2 in/person (level / 水平面)  |  0.3 in/person (stairs / 楼梯)
⚠ CSP 考试技巧 / Exam Tip:
Remember the capacity factors: 0.2 in/person on level surfaces, 0.3 in/person on stairs. Stairs get MORE width per person because people move slower and more carefully. The 32-inch minimum clear door width is a frequently tested baseline. 记住容量因子：水平面每人0.2英寸，楼梯每人0.3英寸。楼梯因人们移动更慢、更谨慎而获得更多每人宽度。32英寸最小净开门宽度是常考基准。
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: A business occupancy must evacuate 400 persons via level corridors. What total corridor width is required? 某办公场所经水平走廊疏散400人，所需总宽度？
答题要点 / Key point: Width = Occupant Load × Capacity Factor → 400 × 0.2 in/person = 80 in. 宽度 = 人员负荷 × 容量因子（水平0.2英寸/人，楼梯0.3英寸/人）。

13.3 NFPA 72——火灾报警与信号规范 · NFPA 72 — Fire Alarm and Signaling Code☆

📖 来源 / Sources: NFPA 72 (Fire Alarm and Signaling Code) · Brauer Ch.16 (Fire Protection and Prevention)

NFPA 72 governs the design, installation, testing, and maintenance of fire alarm systems, including detection, notification, and supervisory functions. NFPA 72管辖火灾报警系统的设计、安装、测试和维护，包括探测、通知和监控功能。

Initiation Devices (Detection) / 启动装置（探测）

Type / 类型Detection Principle / 探测原理Best Application / 最佳应用
离子感烟探测器Smoke — Ionization☆ Current disruption by smoke particles between electrodes烟雾颗粒在电极之间破坏电流 Fast-flaming fires with small particles产生小颗粒的快速明火火灾
光电感烟探测器Smoke — Photoelectric☆ Light scattering or obscuration by smoke particles烟雾颗粒的光散射或遮蔽 Smoldering fires with larger particles; fewer nuisance alarms产生较大颗粒的阴燃火灾；较少误报
定温探测器Heat — Fixed Temperature☆ Activates at a specific temperature (e.g., 135F/57C or 190F/88C) Kitchens, dusty areas, garages (where smoke detectors cause nuisance alarms)厨房、多尘区域、车库（烟雾探测器易误报处）
差温探测器Heat — Rate-of-Rise☆ Activates when temperature rises faster than a set rate (typically 15F/min) Faster than fixed-temperature; self-restoring比定温更快；可自复位
火焰探测器——紫外/红外Flame — UV/IR☆ Senses ultraviolet or infrared radiation from flames High-hazard areas needing very rapid detection (hangars, fuel racks, chemical plants)需极快探测的高风险区域（机库、燃料装卸台、化工厂）
手动报警按钮Manual Pull Stations☆ Human activation / 人工启动 Max travel distance to nearest pull station: 200 ft (unsprinklered), 400 ft (sprinklered)到最近报警按钮最大行走距离：200英尺（无喷淋）、400英尺（有喷淋）

Notification Appliances / 通知装置

Devices that alert occupants: audible / 声音 (horns, bells, voice evacuation speakers), visual / 视觉 (strobes for hearing-impaired, ADA requirements), and tactile / 触觉 (vibrating pagers for deaf/blind). Public mode audible signals must be at least 15 dBA above ambient or 75 dBA minimum (whichever is greater). 提醒居住者的装置：声音（喇叭、铃铛、语音疏散扬声器）、视觉（供听力障碍者的频闪灯，ADA要求）和触觉（供聋/盲者的振动寻呼机）。公共模式声音信号必须至少比环境噪声高15 dBA或最低达到75 dBA（以较大者为准）。

⚠ CSP 考试技巧 / Exam Tip:
Ionization detects flaming fires (small particles); photoelectric detects smoldering fires (large particles). Heat detectors (fixed temp or rate-of-rise) are used where smoke detectors give false alarms. UV/IR flame detectors give the fastest response in high-hazard areas. 离子型检测明火火灾（小颗粒）；光电型检测阴燃火灾（大颗粒）。在烟雾探测器易误报处使用定温或差温热探测器。UV/IR火焰探测器在高风险区域响应最快。
⚖️ 易混淆对比 / Common Confusions:
概念A概念B关键区别
Ionization 离子探测器Photoelectric 光电探测器Ionization = flaming fires (small particles); Photoelectric = smoldering fires (large particles). 离子测明火，光电测阴燃。
Fixed-temperature 定温Rate-of-rise 差温Fixed activates at set temp; rate-of-rise activates on rapid increase (~15°F/min) and self-restores. 差温更快、可自复位。
Manual pull station 200 ftManual pull station 400 ft200 ft unsprinklered vs 400 ft sprinklered. 无喷淋200英尺 vs 有喷淋400英尺。
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: Which detector is MOST appropriate for a kitchen where smoke detectors cause nuisance alarms? 厨房烟雾探测器易误报，应选哪种？
答题要点 / Key point: Heat detectors (fixed-temperature or rate-of-rise) for kitchens, dusty areas, garages. 厨房/多尘/车库用热探测器。UV/IR flame detectors give the FASTEST response in high-hazard areas.

13.4 燃烧四面体与灭火原理 · Fire Tetrahedron & Extinguishment☆

📖 来源 / Sources: Brauer Ch.16 (Fire Protection and Prevention) · Yates Ch.10 (Fire Protection and Prevention)

The Fire Tetrahedron / 燃烧四面体

Four elements must be present for combustion: Fuel / 燃料, Oxygen / 氧气, Heat / 热量, and Chemical Chain Reaction / 化学链式反应. Removing ANY one element extinguishes the fire: 燃烧需要四个要素：燃料、氧气、热量和化学链式反应。移除任何一个要素即可灭火：

Element Removed / 移除要素Method / 方法Example / 示例
Fuel / 燃料Remove / starve the fuel / 移除/耗尽燃料Shut off gas valve; remove combustibles / 关闭气阀；移走可燃物
Oxygen / 氧气Smothering / 窒息CO2, foam blanket, fire blanket / CO2、泡沫覆盖、灭火毯
Heat / 热量Cooling / 冷却Water stream / 水流
Chain Reaction / 链式反应Chemical interruption / 化学中断Dry chemical powder / 干粉

Fire Classes and Extinguishing Agents / 火灾类别与灭火剂

Class / 类别Fuel Type / 燃料类型Extinguishing Agent / 灭火剂Color Symbol / 颜色符号
A类Class A☆Ordinary combustibles: wood, paper, cloth, trash, plastics普通可燃物：木材、纸、布、垃圾、塑料Water (cools), multipurpose dry chemical, foam水（冷却）、多用途干粉、泡沫Green triangle / 绿色三角形
B类Class B☆Flammable liquids: gasoline, oil, grease, paint, solvents易燃液体：汽油、油、油脂、油漆、溶剂CO2 (smothers), dry chemical (chain reaction), foamCO2（窒息）、干粉（链反应）、泡沫Red square / 红色正方形
C类Class C☆Energized electrical equipment: wiring, panels, appliances, motors带电电气设备：电线、电板、电器、电机CO2, dry chemical (non-conductive). Water is DANGEROUS.CO2、干粉（不导电）。水是危险的。Blue circle / 蓝色圆形
D类Class D☆Combustible metals: magnesium, titanium, sodium, potassium, lithium可燃金属：镁、钛、钠、钾、锂Dry powder (specific to the metal). Water is EXTREMELY DANGEROUS.干粉（针对特定金属）。水极度危险。Yellow star / 黄色星形
K类Class K☆Cooking oils and fats: vegetable oils, animal fats, commercial fryers烹饪用油和油脂：植物油、动物油、商用油炸锅Wet chemical (saponification — turns fats into soap-like foam)湿化学剂（皂化——将油脂转化为肥皂状泡沫）Black hexagon / 黑色六边形
⚠ CSP 考试技巧 / Exam Tip:
Memorize the five classes (A, B, C, D, K) and the DANGEROUS agent for each: water on C (shock), water on D (violent reaction), water on K (spreading fire). Class D requires special dry powder; Class K requires wet chemical via saponification. 记住五个类别（A、B、C、D、K）以及每种情况下危险的灭火剂：C类用水（触电）、D类用水（剧烈反应）、K类用水（火势蔓延）。D类需专用干粉；K类需通过皂化作用的湿化学剂。
🧠 记忆口诀 / Mnemonic: F-O-H-C = Fuel, Oxygen, Heat, Chemical chain reaction（燃料、氧气、热量、化学链式反应）——燃烧四面体四要素，去其一即可灭火。 / The four tetrahedron elements.
⚖️ 易混淆对比 / Common Confusions:
概念A概念B关键区别
Class C 电气火灾Class D 金属火灾C = energized electrical (use CO2/dry chemical, NEVER water); D = combustible metals (special dry powder, water EXTREMELY dangerous).
Class K 烹饪油Class B 易燃液体K = cooking oils/fats — wet chemical (saponification); B = gasoline/oil — CO2/dry chemical/foam.
Color symbols 颜色符号—A=green triangle, B=red square, C=blue circle, D=yellow star, K=black hexagon. 记住各色形标。
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: Which agent is required for a Class K fire involving commercial cooking oils? K类商业烹饪油火灾用何种灭火剂？
答题要点 / Key point: Wet chemical via saponification — converts hot fat into soap-like foam. Class D fires need special dry powder specific to the metal. 湿化学剂通过皂化作用；D类需针对金属的专用干粉。

13.5 NFPA 10——便携式灭火器 · NFPA 10 — Portable Fire Extinguishers☆

📖 来源 / Sources: NFPA 10 (Portable Fire Extinguishers) · Yates Ch.10 (Fire Protection and Prevention) · Brauer Ch.16

Extinguisher Types / 灭火器类型

Type / 类型Agent / 灭火剂Primary Use / 主要用途
Water / 水Pressurized water / 加压水Class A only / 仅A类
Multipurpose Dry Chemical / 多用途干粉ABC powder (e.g., monoammonium phosphate) / ABC干粉（如磷酸铵盐）Classes A, B, C — most common / A、B、C类——最常见
CO2 / 二氧化碳Carbon dioxide gas / 二氧化碳气体Classes B, C — leaves no residue (computer rooms, labs) / B、C类——无残留（机房、实验室）
Foam / 泡沫Aqueous film forming foam / 水成膜泡沫Classes A, B — smothers liquids / A、B类——窒息液体
Wet Chemical / 湿化学Potassium-based solution / 钾基溶液Class K — commercial kitchens / K类——商用厨房
Dry Powder (metal) / 干粉（金属）Special powder / 专用粉末Class D — combustible metals / D类——可燃金属

Travel Distance and Distribution / 行走距离与分布

  • Class A / A类: Max travel distance 75 ft.最大行走距离75英尺。
  • Class B / B类: Max travel distance 50 ft (20-B and smaller); 30 ft (higher-hazard).最大行走距离50英尺（20-B及以下）；30英尺（高风险场所）。
  • Class C / C类: Same as A or B based on underlying fuel; must be non-conductive.与A或B类相同，取决于下方燃料；必须不导电。
  • Class D / D类: Max travel distance 75 ft.最大行走距离75英尺。
  • Class K / K类: Max travel distance 30 ft from cooking appliances.距离烹饪设备最大行走距离30英尺。

Inspection and Maintenance / 检查与维护

Monthly visual inspection / 月度目视检查: In designated location, accessible, pressure gauge in operable range, no visible damage, current inspection tag. Annual maintenance / 年度维护: Thorough external examination and documentation by a trained technician. Hydrostatic testing / 水压试验: Typically every 5 or 12 years depending on type. 在指定位置、可及、压力表在可操作范围、无可见损坏、检查标签有效。年度维护：由受训技术人员彻底外部检查和文件记录。水压试验：按类型通常每5或12年一次。

⚠ CSP 考试技巧 / Exam Tip:
Travel distances: A=75 ft, B=50 ft (30 ft high hazard), D=75 ft, K=30 ft. Monthly visual inspection vs. annual maintenance vs. hydrostatic testing every 5-12 years are distinct requirements — know which is which. 行走距离：A=75英尺，B=50英尺（高风险30英尺），D=75英尺，K=30英尺。月度目视检查、年度维护、每5-12年水压试验是不同要求——要区分。
🧠 记忆口诀 / Mnemonic: PASS = Pull, Aim, Squeeze, Sweep（拔销、瞄准、压把、横扫）——灭火器四步操作顺序。 / Extinguisher operating sequence.
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: What is the maximum travel distance to a Class B extinguisher under NFPA 10? 到B类灭火器的最大行走距离？
答题要点 / Key point: Travel distances: A=75 ft, B=50 ft (30 ft high-hazard), D=75 ft, K=30 ft. Monthly visual inspection vs annual maintenance vs hydrostatic testing (5 or 12 yrs). 行走距离与三种检查频率的区分是常考点。

13.6 喷淋系统 · Sprinkler Systems☆

📖 来源 / Sources: NFPA 13 (Sprinkler Systems) · Brauer Ch.16 (Fire Protection and Prevention) · Yates Ch.10
System Type / 系统类型Description / 描述Activation / 启动Typical Application / 典型应用
湿式系统Wet Pipe☆ Pipes always filled with water under pressure Individual sprinkler heads activate at design temperature (typically 155-286F) Heated buildings, most common. Simple, reliable, lowest maintenance.有暖气建筑，最常见。简单、可靠、维护最少。
干式系统Dry Pipe☆ Pipes filled with pressurized air/nitrogen; water held back by a dry pipe valve Head opens, air pressure drops, valve trips, water flows (delay up to 60 seconds) Unheated areas subject to freezing (warehouses, loading docks, parking garages).易结冰的无暖气区域（仓库、装卸区、停车库）。
雨淋系统Deluge☆ Open heads (no thermal element); water released to ALL heads simultaneously Separate detection system opens the deluge valve High-hazard areas with rapid fire spread (aircraft hangars, chemical plants, power generation).预计火势迅速蔓延的高风险区域（飞机库、化工厂、发电）。
预作用系统Pre-Action☆ Water held back by a pre-action valve; pipes may be dry or supervised with low-pressure air Requires TWO events: (1) detection system activation, (2) individual head fusing Water-sensitive areas (computer rooms, museums, libraries, telecommunications).对水敏感区域（计算机房、博物馆、图书馆、电信设施）。

NFPA 13 is the standard for sprinkler installation. Key design factors: occupancy hazard classification (Light, Ordinary, Extra Hazard), water supply, and head spacing. NFPA 13是喷淋安装标准。关键设计因素：场所危害分类（轻、中、极高危害）、供水、喷头间距。

⚠ CSP 考试技巧 / Exam Tip:
Four types: Wet (water always in pipes), Dry (air in pipes — for freezing areas, delays up to 60s), Deluge (all heads open — for high hazard), Pre-action (two-step — for water-sensitive areas). Pre-action is the ONLY one that requires TWO events before water discharge. 四种类型：湿式（管道始终有水）、干式（管道有空气——用于结冰区域，延迟可达60秒）、雨淋（所有喷头开启——用于高风险）、预作用（两步——用于对水敏感区域）。预作用是唯一需要两个事件才能喷水的系统。
⚖️ 易混淆对比 / Common Confusions:

Deluge 雨淋Pre-action 预作用Deluge = ALL heads open simultaneously (high hazard); Pre-action = needs TWO events (detection + head fusing), for water-sensitive areas.

📝 真题情景 / Exam Scenario:
"A sprinkler system with pressurized air in the pipes is used to protect an unheated warehouse. When a head opens, water flows only after the air pressure drops and the dry pipe valve trips, delaying water discharge up to 60 seconds. What type of system is this?"
最佳答案 / Best answer: Dry pipe system（干式系统）——管道充压空气、靠干式阀挡水，用于易结冰的无暖气仓库。 / Used where pipes could freeze; air-pressure drop trips the valve before water flows.

13.8 危险沟通与安全数据表 · Hazard Communication & Safety Data Sheets☆

📖 来源 / Sources: 29 CFR 1910.1200 (HazCom GHS/SDS) · Brauer Ch.24 (Chemicals) · Yates Ch.2 (Regulations)

The 危险沟通标准Hazard Communication Standard (HCS)☆ (29 CFR 1910.1200), aligned with the 全球化学品统一分类和标签制度Globally Harmonized System (GHS)☆, requires employers to communicate chemical hazards through: (1) a written hazard communication program, (2) container labeling, (3) Safety Data Sheets (SDS), and (4) employee training. 危险沟通标准（HCS，29 CFR 1910.1200）与全球化学品统一分类和标签制度（GHS）对齐，要求雇主通过以下方式传达化学品危害：(1) 书面危险沟通计划，(2) 容器标签，(3) 安全数据表（SDS），和(4) 员工培训。

SDS Sections (16 total) / SDS的16个部分

The SDS has 16 standard sections. Key ones: Section 1 (Identification), Section 2 (Hazard Identification), Section 4 (First-Aid), Section 5 (Fire-Fighting), Section 7 (Handling & Storage), Section 8 (Exposure Controls / PPE), Section 11 (Toxicological), Section 16 (Other). SDS有16个标准部分。关键部分：第1节（标识）、第2节（危害标识）、第4节（急救）、第5节（消防）、第7节（操作与储存）、第8节（暴露控制/PPE）、第11节（毒理学）、第16节（其他）。

Label Elements (GHS) / GHS标签要素

  • Signal word / 信号词: "Danger" (more severe) or "Warning" (less severe)."危险"（更严重）或"警告"（较不严重）。
  • Pictograms / 象形图: 9 standard GHS pictograms (flame, skull, health hazard, corrosion, etc.).9个标准GHS象形图（火焰、骷髅、健康危害、腐蚀等）。
  • Hazard statements (H-codes) / 危险说明（H代码）: e.g., H225 "Highly flammable liquid and vapor."如H225"高度易燃液体和蒸气"。
  • Precautionary statements (P-codes) / 防范说明（P代码）: e.g., P210 "Keep away from heat/sparks/open flames."如P210"远离热源/火花/明火"。
⚠ CSP 考试技巧 / Exam Tip:
The four pillars of Hazard Communication: written program, labels, SDS, and training. GHS "Danger" signals higher severity than "Warning." The SDS is the primary reference for PPE selection, first aid, and fire-fighting measures. 危险沟通四支柱：书面计划、标签、SDS和培训。GHS"危险"信号词的严重性高于"警告"。SDS是选择PPE、急救和消防措施的主要参考。
🧠 记忆口诀 / Mnemonic: WLST = Written program, Labels, SDS, Training（书面计划、标签、SDS、培训）——危险沟通四支柱。 / The four pillars of Hazard Communication.
🎯 高频考点 / Exam Hotspot 必考 HIGH
典型问法 / Typical question: Which SDS section contains exposure controls and PPE recommendations? SDS第几节含暴露控制与PPE？
答题要点 / Key point: Section 8 (Exposure Controls / PPE). Section 2 = hazard identification (carcinogenicity), Section 9 = physical/chemical properties, Section 11 = toxicology (LD50). GHS "Danger" = more severe than "Warning." 熟记SDS关键章节号。

13.9 工作场所暴力预防 · Workplace Violence Prevention☆

📖 来源 / Sources: Brauer Ch.29 (Emergencies and Security) · Brauer Ch.31 (Human Behavior and Performance)

Types of Workplace Violence (I-IV) / 工作场所暴力类型（I-IV）

Type / 类型Perpetrator / 施暴者Relationship / 关系Typical Settings / 典型场景
类型I——犯罪意图Type I — Criminal Intent☆ No legitimate relationship to the business Stranger committing a crime (robbery, trespassing) Retail (late-night), convenience stores, banks, taxi drivers
类型II——客户/被服务者Type II — Customer/Client☆ Recipient of services; customer, client, patient, student Becomes violent while being served Healthcare, social services, education, law enforcement
类型III——员工之间Type III — Worker-on-Worker☆ Current or former employee Attacks or threatens coworkers, supervisors, managers All workplaces; often triggered by discipline or termination
类型IV——个人关系Type IV — Personal Relationship☆ Personal relationship with employee (not the business) Domestic violence spilling into the workplace All workplaces; perpetrator is spouse/partner of target employee

通过环境设计预防犯罪 · CPTED — Crime Prevention Through Environmental Design☆

  • Natural Surveillance / 自然监视: Design so legitimate users can see and be seen (open sightlines, lighting, window placement).设计使合法使用者可以看到并被看到（开放视线、照明、窗户布局）。
  • Territorial Reinforcement / 领域强化: Delineate private vs. public space with fencing, signage, landscaping.用围栏、标识、景观区分私人与公共空间。
  • Access Control / 出入控制: Limit and channel movement (single entries, key cards, turnstiles, bollards).限制和引导通行（单一入口、门禁卡、旋转门、防撞柱）。
  • Maintenance / Image / 维护/形象: Well-maintained properties signal care and monitoring ("broken windows theory").维护良好的物业表明有人关心和监控（"破窗理论"）。

Threat Assessment Teams / 威胁评估团队

Multidisciplinary teams (HR, security, legal, mental health/EAP, management) evaluate reports of concerning behavior. Purpose: assess threat seriousness, develop interventions, prevent violence. Key focus: behavior-based assessment, not profiling. 多学科团队（人力资源、安保、法律、心理健康/EAP、管理层）评估关注行为的报告。目的：评估威胁严重性、制定干预、预防暴力。关键焦点：基于行为的评估，而非画像分析。

Warning Signs of Potential Violence / 潜在暴力的警示信号

  • Verbal threats or intimidation / 口头威胁或恐吓
  • Obsession with weapons or violence / 对武器或暴力的执迷
  • Paranoid or grievance-driven statements / 偏执或抱怨驱动言论
  • Social isolation and withdrawal / 社交孤立与退缩
  • Marked change in behavior or performance / 行为或表现的显著变化
  • Substance abuse / 物质滥用
  • Interest in previous incidents of workplace violence / 对以往工作场所暴力事件的兴趣
⚠ CSP 考试技巧 / Exam Tip:
Type I = stranger/robber (most common fatal type, late-night retail). Type II = customer/client (healthcare). Type III = worker-on-worker. Type IV = domestic relationship. CPTED has four elements: surveillance, territorial reinforcement, access control, maintenance. 类型I = 陌生人/抢劫者（最常见致命类型，深夜零售）。类型II = 客户/患者（医疗保健）。类型III = 员工之间。类型IV = 家庭关系。CPTED四要素：监视、领域强化、出入控制、维护。
🧠 记忆口诀 / Mnemonic: S-T-A-M = Surveillance, Territorial reinforcement, Access control, Maintenance（监视、领域强化、出入控制、维护）——CPTED四要素。 / The four CPTED elements.

"A nurse is assaulted by a patient during treatment. A convenience store clerk is robbed at gunpoint by an unknown person. An employee is attacked by their estranged spouse in a domestic incident. Which workplace violence types are these?"
最佳答案 / Best answer: Nurse = Type II (Customer/Client); Clerk = Type I (Criminal Intent); Spouse = Type IV (Personal Relationship). 医护=II类，抢劫=I类，配偶=IV类。
